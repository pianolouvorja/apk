# Política de Privacidade — LouvorJA PIANO

Última atualização: 15 de agosto de 2026

## 1. Visão geral

O LouvorJA PIANO ("aplicativo") é um aplicativo de gerenciamento de cultos que oferece acesso a coletâneas de hinos, letras, áudio (vocal e instrumental), leitura bíblica, liturgia e ferramentas de apoio para igrejas.

Esta política descreve como tratamos dados quando você utiliza o aplicativo.

## 2. Dados coletados

O aplicativo **não coleta, armazena nem transmite dados pessoais identificáveis** para nós.

- **Não há cadastro de conta**: o aplicativo não pede nome, e-mail, telefone ou documento.
- **Não há rastreamento**: não utilizamos SDKs de analytics, publicidade ou rastreamento de terceiros.
- **Configurações locais**: idioma, tema e nome de igreja/distrito ficam armazenados apenas no seu dispositivo e não são enviados a servidores.

## 3. Conteúdo de terceiros

- **Catálogo de hinos e Bíblia**: o aplicativo consome a API pública da LouvorJA (api.louvorja.com.br) para listar hinos, letras e textos bíblicos. As requisições contêm apenas o identificador do conteúdo solicitado.
- **Áudio**: o streaming de áudio é servido diretamente pelos servidores da LouvorJA. Nenhum dado pessoal acompanha as requisições.

## 4. Atualizações do aplicativo

O verificador de atualizações consulta a API do GitHub (api.github.com) para informar novas versões. A requisição é anônima — apenas o número da versão atual é comparado.

## 5. Downloads offline

Hinos baixados para uso offline são armazenados apenas no armazenamento do seu dispositivo. Podem ser removidos a qualquer momento dentro do aplicativo. A desinstalação do aplicativo remove todos os arquivos.

## 6. Permissões do Android

- **INTERNET**: acesso ao catálogo, áudio e verificação de atualizações.
- Nenhuma outra permissão sensível é solicitada (sem câmera, microfone, contatos ou localização).

## 7. Crianças

O aplicativo não é direcionado a crianças e não coleta dados de usuários de qualquer idade.

## 8. Alterações nesta política

Alterações serão publicadas nesta página com data atualizada, e em versões futuras do aplicativo quando aplicável.

## 9. Contato

Dúvidas sobre privacidade: abra uma issue em https://github.com/pianolouvorja/apk/issues
